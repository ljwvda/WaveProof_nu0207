# Existence proof of traveling wave solution for the Navier-Stokes equations

This repository contains the code corresponding to the proof of a traveling wave solution at nu=0.2069 in the Navier-Stokes equations, written by Lindsey van der Aalst and Jan Bouwe van den Berg.

---

## How to run the proofs

Run the following file to reproduce the results in the paper:

- [`WaveProof_nu0207.m`](WaveProof_nu0207.m) 

---

## Requirements

To obtain rigorous proofs, [INTLAB](https://www.tuhh.de/ti3/rump/) is required.  
You can also run the proof without interval arithmetic, by commenting line 12 in WaveProof_nu0207.m

### Version

- MATLAB: **2024a**
